💡 Cheat Sheet โครงสร้าง Scikit-Learn

ทุกโมดูลใน Scikit-learn ใช้ API รูปแบบเดียวกันหมด:

  • .fit(X, y) - ฝึกสอนโมเดล
  • .predict(X) - ทำนายผลลัพธ์
  • .score(X, y) - วัดค่า Accuracy / R²

บทที่ 08

Linear Regression

  • สมการโมเดล: $\hat{y} = w \cdot x + b$
  • Least Squares Loss (SSE): $$E(w,b) = \sum_{i=1}^n (y_i - b - w \cdot x_i)^2$$
  • Closed-Form Solution: $$w = \frac{\sum x_i y_i - \frac{1}{n}(\sum x_i)(\sum y_i)}{\sum x_i^2 - \frac{1}{n}(\sum x_i)^2}, \quad b = \bar{y} - w \cdot \bar{x}$$
  • การวัดผล: MSE, RMSE, $R^2$
  • ข้อควรระวัง: ไวต่อ Outlier มาก และการทำนายนอกช่วงข้อมูลฝึก (Extrapolation) มีความเสี่ยงสูง
บทที่ 09

K-NN & Classification

  • หลักการ: วัดระยะทางหาเพื่อนบ้านใกล้สุด $K$ ตัว แล้วโหวตเสียงข้างมาก
  • การเลือก K:
    • $K$ เล็ก $\rightarrow$ Overfitting (Variance สูง)
    • $K$ ใหญ่ $\rightarrow$ Underfitting (Bias สูง)
  • ข้อแนะนำ: ใช้ $K$ เป็นเลขคี่เสมอเพื่อป้องกันการโหวตเสมอ
  • StandardScaler: $z = \frac{x - \mu}{\sigma}$
บทที่ 10

Decision Tree (ID3)

  • โครงสร้าง: Root Node $\rightarrow$ Decision Node $\rightarrow$ Leaf Node (Class)
  • Entropy รวม: $$H(S) = -\sum_{i=1}^c p_i \log_2(p_i)$$
  • Weighted Entropy: $$Entropy(S, A) = \sum_{v \in Values(A)} \frac{|S_v|}{|S|} H(S_v)$$
  • Information Gain: $$Gain(S, A) = H(S) - Entropy(S, A)$$
บทที่ 11

Neural Network (ANN)

  • สมการนิวรอน: $\hat{y} = f(\sum w_i x_i + b)$
  • Sigmoid Activation: $$\sigma(z) = \frac{1}{1 + e^{-z}}$$
  • Perceptron Update Rule: $$w_{i, \text{new}} = w_{i, \text{old}} - \eta (\hat{y} - y) x_i$$
  • Forward Pass: $$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \quad a^{(l)} = f(z^{(l)})$$

🧮 ขั้นตอนการคำนวณสำหรับข้อสอบเขียนตอบ (Decision Tree & ANN)

1. การคำนวณ Decision Tree (ID3 Algorithm)

  1. คำนวณ Entropy รวม $H(S)$: หาจากสัดส่วนคลาสเป้าหมายทั้งหมดในตาราง
  2. คำนวณ Entropy แยกกลุ่มย่อย $H(S_v)$: สำหรับทุกค่าความเป็นไปได้ของ Feature นั้น
  3. คำนวณ Weighted Entropy:
    $$Entropy(S, A) = \sum \frac{|S_v|}{|S|} H(S_v)$$
  4. คำนวณ Information Gain:
    $$Gain(S, A) = H(S) - Entropy(S, A)$$
  5. เลือก Root Node: เลือก Feature ที่ได้ค่า $Gain$ สูงที่สุด

2. ขั้นตอนคำนวณ ANN (Forward & Backward Pass)

  • Forward Pass:
    $$z_1 = W_1 x + b_1 \quad \rightarrow \quad h = \sigma(z_1)$$ $$z_2 = W_2 h + b_2 \quad \rightarrow \quad \hat{y} = \sigma(z_2)$$
  • Output Error Gradient ($\delta_2$): $$\delta_2 = (\hat{y} - t) \cdot \hat{y}(1 - \hat{y})$$
  • Hidden Error Gradient ($\delta_1$): $$\delta_1 = (W_2^T \delta_2) \odot h(1 - h)$$
  • Weight & Bias Update: $$W_{\text{new}} = W_{\text{old}} - \eta \cdot \frac{\partial L}{\partial W}, \quad b_{\text{new}} = b_{\text{old}} - \eta \cdot \delta$$

Decision Tree Classifier (ID3 ใช้ criterion='entropy') from sklearn.tree import DecisionTreeClassifier dt_model = DecisionTreeClassifier(criterion='entropy', random_state=42) dt_model.fit(X_train, y_train) dt_pred = dt_model.predict(X_test) # 3. Artificial Neural Network (MLPClassifier) from sklearn.neural_network import MLPClassifier mlp_model = MLPClassifier(hidden_layer_sizes=(4,), activation='logistic', max_iter=1000, random_state=42) mlp_model.fit(X_train, y_train) mlp_pred = mlp_model.predict(X_test) # 4. การวัดประเมินผล (Evaluation Metrics) from sklearn.metrics import accuracy_score, classification_report, mean_squared_error acc = accuracy_score(y_test, dt_pred) print("Accuracy:", acc) print(classification_report(y_test, dt_pred))
